# Speakbase

Студия английского и подготовки к TOEFL для Марины и Владлена.

## Локальный запуск

В корне проекта выполни `python -m http.server 8000` и открой [http://localhost:8000](http://localhost:8000). Для кабинета используется действующий аккаунт Supabase.

## Проверка курса

`node test-course.cjs` проверяет сборку уроков для всех 404 дат в двух профилях и в вариантах Reading и Writing. Проверка охватывает наличие шести учебных этапов и ключей к вопросам с выбором ответа.

## Экзаменационный режим

В текущей версии доступна 60-минутная учебная симуляция из 34 заданий. Полноформатные официальные материалы доступны на [сайте ETS](https://www.ets.org/toefl/test-takers/ibt/prepare.html).
