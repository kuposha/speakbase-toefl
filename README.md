# Speakbase

Личная студия английского для подготовки к TOEFL iBT.

**Сайт:** https://kuposha.github.io/speakbase-toefl/

## Учебный маршрут
- 404 календарных дня, 46 тем грамматики с теорией и пояснениями, Vocabulary, Reading, Listening, Speaking и Writing.
- Два отдельных профиля с хранением прогресса и записей в Supabase.

## Экзаменационная практика
24 оригинальных неофициальных пробника с фиксированным маршрутом: Reading (50), Listening (47), Writing (12), Speaking (11); 120 заданий, до 90 минут на вариант. Всего 2 880 заданий, 696 MP3 для Listening и 264 WAV для Speaking. Озвучивание синтетическое. В полном режиме запись доступна один раз, в тренировке отдельной секции — повторно. Открытые ответы проверяются по критериям и примерам, без обещания официального балла ETS. Варианты не адаптивны и не эквивалентны по психометрической сложности официальным экзаменам. Официальные материалы: https://www.ets.org/toefl/test-takers/ibt/prepare.html

## Локальный запуск
В корне проекта: `python -m http.server 8000`, затем http://localhost:8000.

## Проверки
- `node test-content.cjs` — структура 46 грамматических тем.
- `node test-course.cjs` — 1 616 комбинаций календаря и навыков.
- `node test-exam-data.cjs` — структура, уникальность, ключи и аудиофайлы.
- `node test-practice-bank.cjs` — сессии по 10 заданий, разнообразие и ротация заданий, фильтрация Writing по уровню и форматы проверки ответов.
- `node test-practice-browser.cjs` — проверка Listening через интерфейс: прослушивание, разблокировка вопроса, четыре варианта, отправка ответа и переход к другой записи.
- `node test-browser.cjs`, `node test-exam-browser.cjs` — локальные UI-сценарии (Playwright, Edge, тестовые данные).
- `node test-public.cjs` — опубликованный сайт.
- `node test-cloud-browser.cjs` — отдельная проверка Supabase с двумя выделенными тестовыми аккаунтами; требует QA_ACCOUNTS в окружении. Реальный вход личных пользователей и межустройственная синхронизация пока не подтверждены.

Содержимое и ключи прошли структурный контроль; независимая экспертная калибровка уровня и сложности не проводилась.
