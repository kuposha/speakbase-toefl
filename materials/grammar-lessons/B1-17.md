## 4. Полный конспект

### 4.1. Основная идея и функция конструкции

Обстоятельственные придаточные и близкие конструкции связывают причины, цели, последствия и противопоставления. Важны два решения: какое логическое отношение выражается и какая грамматическая структура следует после связующего слова.

Because it rained — причина, so that we could stay dry — цель, so we stayed inside — следствие, although it rained — уступка. Несмотря на близкие русские переводы, because и because of требуют разных продолжений. Although и despite также не взаимозаменяемы без изменения структуры. Придаточное может стоять перед главной частью или после неё; при начальном придаточном обычно нужна запятая.

### 4.2. Формирование и грамматическая модель

| Отношение | Модель | Пример |
|---|---|---|
| Причина | because/since/as + subject + verb | We stayed because it rained. |
| Причина | because of + noun/V-ing | We stayed because of the rain. |
| Цель | to/in order to + V1 | I called to ask a question. |
| Цель | so that + subject + verb | I called so that she could help. |
| Следствие | so + clause | It rained, so we stayed. |
| Степень и следствие | so + adjective/adverb + that | It was so cold that we left. |
| Степень и следствие | such + noun phrase + that | It was such a cold day that we left. |
| Уступка | although/even though + clause | Although it rained, we left. |
| Уступка | despite/in spite of + noun/V-ing | Despite the rain, we left. |
| Сопоставление | whereas/while + clause | A is cheap, whereas B is fast. |

Because of, despite, in spite of — предложные конструкции: после них noun, pronoun или -ing. Возможна развёрнутая форма despite the fact that + clause. In order to и so as to вводят инфинитив цели; отрицание цели — in order not to / so as not to. So that полезен при разных подлежащих: I opened the door so that she could enter. Such требует существительной группы: such a difficult task, such difficult tasks, such useful information.

### 4.3. Как выбрать подходящую форму

Определи, отвечает ли вторая часть на «почему?», «зачем?», «что из этого вышло?» или «вопреки чему?». После союза because/although проверяй наличие подлежащего и сказуемого, после because of/despite — именной группы. Для цели с тем же исполнителем часто достаточно to V1, для отдельного подлежащего — so that + clause.

Since и as могут обозначать причину, но имеют и временные значения, поэтому контекст должен быть ясным. Whereas и while сопоставляют факты; although уступает обстоятельству, которое обычно мешало бы результату. So that обозначает цель, которую участник стремится достичь, тогда как so…that обозначает результат степени качества или количества.

### 4.4. Сравнение с близкими конструкциями

| Пример | Функция |
|---|---|
| Because the road was icy, we drove slowly. | Причина. |
| Because of the ice, we drove slowly. | Та же причина с noun phrase. |
| We drove slowly so that we could stay safe. | Цель. |
| The road was icy, so we drove slowly. | Следствие. |
| Although the road was icy, we continued. | Уступка. |
| Despite the ice, we continued. | Уступка с noun phrase. |

### 4.5. Примеры с переводом и объяснением

| English | Перевод | Почему это подходит |
| --- | --- | --- |
| Although the room was small, the event was successful. | Хотя комната была маленькой, мероприятие прошло успешно. | Уступка с придаточным. |
| Despite the delay, we completed the test. | Несмотря на задержку, мы завершили тест. | Уступка с существительным. |
| We left early in order to avoid traffic. | Мы вышли рано, чтобы избежать пробок. | Цель. |
| She spoke slowly so that everyone could understand. | Она говорила медленно, чтобы все могли понять. | Цель с отдельным subject. |
| It was such a difficult task that we needed help. | Задание было настолько сложным, что нам потребовалась помощь. | Степень и следствие. |

### 4.6. Исключения, ограничения и границы употребления

Не соединяй Although X, but Y в стандартной структуре одного сложного предложения. Используй Although X, Y или X, but Y. Similarly, Because X, so Y обычно требует выбора одной связи. Despite не требует of; in spite of требует of. Не путай so + adjective с such + noun phrase.

После so much/many/few/little + noun используется so, а не such: so many questions that… . Such a/an + adjective + singular countable noun требует артикля; с plural/uncountable артикль a/an не нужен. For + -ing часто обозначает назначение предмета (a tool for measuring), а не причину действия человека (I came to measure). Следи, чтобы подразумеваемый исполнитель инфинитива цели был понятен.

### 4.7. Типичные ошибки русскоязычных студентов

| Ошибка | Исправление | Объяснение |
| --- | --- | --- |
| Despite it was raining, we left. | Although it was raining, we left. | После despite не ставят обычное придаточное. |
| Although it was late, but we stayed. | Although it was late, we stayed. | But лишний при although. |
| I went there for asking a question. | I went there to ask a question. | Цель действия — инфинитив. |
| It was so a difficult task that we stopped. | It was such a difficult task that we stopped. | Such + noun phrase. |

### 4.8. Произношение и восприятие на слух

Начальная обстоятельственная часть обычно отделяется небольшой паузой: Although it was LATE, we continued. Выделяй смысловое противопоставление или причину, а не все служебные слова подряд. В so that и in order to служебные слова часто безударны.

Сначала прослушай или прочитай пример, затем произнеси его целиком. Обрати внимание на смысловое ударение и форму конструкции; не ориентируйся только на буквенный перевод.

### 4.9. Академический английский и TOEFL-перенос

В Reading различай причины и результаты, не принимай уступку за причинно-следственное утверждение. В Writing обосновывай решения и показывай ограничения: Although the sample was small, the pattern was consistent. В Speaking объясняй, зачем предпринималось действие, и какое следствие действительно наблюдалось.

Это авторская практика переноса навыка. Она не является официальным заданием TOEFL и не выдаётся за официальный результат экзамена.

### 4.10. Примеры для управляемого разбора

- Although the room was small, the event was successful. — Хотя комната была маленькой, мероприятие прошло успешно. Уступка с придаточным.
- Despite the delay, we completed the test. — Несмотря на задержку, мы завершили тест. Уступка с существительным.
- We left early in order to avoid traffic. — Мы вышли рано, чтобы избежать пробок. Цель.

Для каждого примера назови целевую конструкцию, объясни выбор и составь новое предложение в другом контексте. Затем перейди к заданиям: сначала диагностика, затем управляемая и самостоятельная практика, затем новые вопросы выходной проверки.

### 4.11. Самопроверка

Перед отправкой ответа проверь:
1. Причина и следствие не перепутаны.
2. Because/although вводят clause.
3. Because of/despite вводят подходящую группу.
4. Цель выражена to или so that.
5. So/such согласованы со структурой.
6. Уступка и сопоставление логичны; пунктуация корректна.

### 4.12. Краткая памятка

Because/although + clause; because of/despite/in spite of + noun/V-ing. To/in order to и so that — цель; so — следствие; so…that/such…that — степень и результат. Whereas — сопоставление. Выбирай союз по логике и структуре.

Не выбирай форму только по одному знакомому слову: проверь контекст, значение и структуру. При ошибке вернись к соответствующей части конспекта и составь собственный пример.
