## 3. Место темы и границы

There is/are вводит новый объект или факт наличия; it is описывает или идентифицирует уже известный объект. Согласование зависит от noun phrase после be.

## 4. Полный конспект

### 4.1. Основная идея и функция конструкции

There is / there are сообщает, что что-то существует или находится в каком-либо месте. There is a lamp on the table — на столе есть лампа. В этой конструкции there не означает «там» буквально, а вводит сообщение о наличии.

Сравни There is a book on the desk (сообщаем, что книга есть) и The book is on the desk (сообщаем местонахождение известной книги). В первом случае начинаем с there, во втором — с конкретного subject. Русский перевод может звучать одинаково, но фокус разный.

### 4.2. Формирование и грамматическая модель

| Тип | Singular/uncountable | Plural |
|---|---|---|
| Утверждение | There is a chair. | There are chairs. |
| Отрицание | There isn't a chair. | There aren't any chairs. |
| Вопрос | Is there a chair? | Are there any chairs? |
| Ответ да | Yes, there is. | Yes, there are. |
| Ответ нет | No, there isn't. | No, there aren't. |

Singular countable обычно с a/an: There is an apple. Plural — some/two/many + noun или noun без определителя. Uncountable — some water, no milk, information: There is some water. В отрицаниях и обычных вопросах часто any: There isn't any water. Are there any chairs? No может стоять перед noun с утвердительным be: There are no chairs.

### 4.3. Как выбрать подходящую форму

Сначала реши, сообщаешь ли о наличии. Затем найди noun после there. Один предмет или неисчисляемое количество — is; несколько предметов — are. В вопросе переставь is/are перед there. В отрицании добавь not после be.

How many + plural noun + are there? спрашивает количество: How many desks are there? How much + uncountable + is there? спрашивает объём: How much water is there? В кратком ответе сохраняй there: Yes, there is, не Yes, it is.

### 4.4. Сравнение с близкими конструкциями

| Наличие | Известный объект |
|---|---|
| There is a cat outside. | The cat is outside. |
| There are two desks here. | The desks are here. |
| Is there a cafe nearby? | Is the cafe nearby? |
| There is some tea. | The tea is hot. |

### 4.5. Примеры с переводом и объяснением

| English | Перевод | Почему это подходит |
| --- | --- | --- |
| There is a clock above the door. | Над дверью есть часы. | Один предмет, is. |
| There are four desks in the room. | В комнате четыре стола. | Plural, are. |
| There isn't any milk in the fridge. | В холодильнике нет молока. | Uncountable, isn't. |
| Is there a printer here? | Здесь есть принтер? | Is перед there. |
| Are there any seats left? | Остались свободные места? | Seats plural. |
| How many pages are there? | Сколько страниц? | How many + plural + are there. |

### 4.6. Исключения, ограничения и границы употребления

В разговорной речи встречается there's перед множественным числом, особенно при перечислении, но в нейтральном учебном письме согласуй are с plural. Для перечисления разных предметов возможны особенности согласования, поэтому сначала тренируем ясные singular/plural группы.

There's = there is в настоящем уроке. There is no milk и There isn't any milk равнозначны по наличию; не используй there isn't no milk в стандартной письменной речи. Для прошлого there was/were; для будущего there will be (подробнее позже). Не путай There is a problem и It is a problem: it указывает на уже известный предмет/ситуацию.

### 4.7. Типичные ошибки русскоязычных студентов

| Ошибка | Исправление | Объяснение |
| --- | --- | --- |
| There are a clock. | There is a clock. | Один предмет. |
| There is two chairs. | There are two chairs. | Plural требует are. |
| Do there is a bank? | Is there a bank? | Be образует вопрос без do. |
| Yes, it is. (наличие) | Yes, there is. | В ответе на Is there повторяем there. |

### 4.8. Произношение и восприятие на слух

Произноси there is и there are, затем there's. В кратком ответе Yes, there is оставляй полную форму. Вопросы Is there…? и Are there…? произноси с ясным начальным be. Отдельная аудиосверка открыта.

Сначала прослушай или прочитай пример, затем произнеси его целиком. Обрати внимание на смысловое ударение и форму конструкции; не ориентируйся только на буквенный перевод.

### 4.9. Академический английский и TOEFL-перенос

В Listening распознавай, какие ресурсы доступны. В Speaking опиши учебную аудиторию, в Writing укажи наличие или отсутствие информации: There is a problem with the file. Это базовая практика.

Это авторская практика переноса навыка. Она не является официальным заданием TOEFL и не выдаётся за официальный результат экзамена.

### 4.10. Примеры для управляемого разбора

- There is a clock above the door. — Над дверью есть часы. Один предмет, is.
- There are four desks in the room. — В комнате четыре стола. Plural, are.
- There isn't any milk in the fridge. — В холодильнике нет молока. Uncountable, isn't.

Для каждого примера назови целевую конструкцию, объясни выбор и составь новое предложение в другом контексте. Затем перейди к заданиям: сначала диагностика, затем управляемая и самостоятельная практика, затем новые вопросы выходной проверки.

### 4.11. Самопроверка

Перед отправкой ответа проверь:
1. Is/are согласованы.
2. A/an и some/any употреблены по типу noun.
3. В вопросах be перед there.
4. Отрицание после be.
5. Краткие ответы сохраняют there.
6. Наличие и местонахождение известного предмета различены.

### 4.12. Краткая памятка

There is + singular/uncountable; there are + plural. Is/Are there…? There isn't/aren't… . Yes, there is/are. No, there isn't/aren't. Не путай наличие с описанием известного объекта.

Не выбирай форму только по одному знакомому слову: проверь контекст, значение и структуру. При ошибке вернись к соответствующей части конспекта и составь собственный пример.
