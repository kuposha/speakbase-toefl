## 3. Место темы и границы

Различай unless, provided/providing, as long as, in case и even if по логике условия и семантическим ограничениям.

## 4. Полный конспект

### 4.1. Основная идея и функция конструкции

Проверь, зависит ли результат от условия. You may enter provided that you sign in — регистрацию требуют для входа. Even if you sign in, you cannot enter — регистрация не меняет запрета.

### 4.2. Формирование и грамматические модели

Unless часто заменяет if … not. В I won't go unless Jo calls отсутствие звонка исключает поездку, но сам звонок ещё не гарантирует её. In case объясняет, почему готовятся заранее: Take cash in case the reader fails.

### 4.3. Как выбрать подходящую форму

As long as бывает временным («пока») и условным («при условии что»). Определи связь по главной части. После supposing можно представить маловероятную ситуацию с Past Simple. Не ставь will механически в обычное будущее условие.

### 4.4. Сравнение с близкими конструкциями

| Form | Example | Meaning |
|---|---|---|
| in case + clause | Take a map in case you get lost. | Prepare now because the event is possible |
| if + clause | I'll take a map if I get lost. | Take action only if the event happens |
| in case of + noun | In case of fire, leave the building. | If there is a fire; notice/instruction |
| unless | You can't enter unless you are a member. | Except if / if not |
| as long as | You can borrow it as long as you return it. | Permission depends on a condition |
| provided/providing | We'll go provided the weather is good. | A required condition |
| even if | Even if it rains, we'll go. | The result remains despite the condition |

### 4.5. Примеры с переводом и объяснением

| English | Перевод | Почему это подходит |
|---|---|---|---|
| `You can borrow the equipment provided that you return it by Friday.` | Ты можешь взять оборудование при условии, что вернёшь его до пятницы. | Provided that introduces a necessary condition for permission. |
| `Take a printed map in case your phone battery dies.` | Возьми бумажную карту на случай, если разрядится аккумулятор телефона. | In case introduces a possible future event for which preparation is made. |
| `Even if the cost increases, the project will continue.` | Даже если расходы вырастут, проект продолжится. | Even if signals that the result remains the same despite the condition. |
| `The contract is valid on condition that both parties sign it.` | Договор действителен при условии, что обе стороны его подпишут. | On condition that introduces a requirement that must be satisfied. |

Примеры составлены Speakbase. Они иллюстрируют грамматическую функцию, но не подменяют индивидуальную проверку всех возможных вариантов и исключений.

### 4.6. Исключения, ограничения и границы употребления

- In case is a precaution marker, not a simple synonym of if. It can refer to a future possibility (*in case it rains*) or a past precaution (*I took a map in case I got lost*).
- Do not normally use will after in case, unless, as long as, so long as, provided or providing in an ordinary future conditional clause.
- In case of is followed by a noun phrase: *in case of emergency*, not *in case of something happens*.
- Unless already means except if/if not; avoid an additional negative unless the intended meaning is carefully controlled.
- Provided/providing and as long as make the result dependent on a condition; they do not express precaution. As/so long as can also express duration, so inspect the meaning.
- Even if is concessive/hypothetical: the result is unchanged even if the condition occurs. Even though presents the contrast as a fact.
- Do not confuse in case + clause with in case of + noun phrase.
- Use a full clause after unless/provided/as long as; use a noun phrase after in case of. On condition that is formal; supposing/suppose frames a hypothetical possibility.

### 4.7. Типичные ошибки русскоязычных студентов

| `You can borrow the equipment even if you return it by Friday.` | `You can borrow the equipment provided that you return it by Friday.` | Even if means the result remains true regardless of the condition. |
| `Take a printed map unless your phone battery dies.` | `Take a printed map in case your phone battery dies.` | Unless means if not and changes the logic. |
| `Provided that the cost increases, the project will continue.` | `Even if the cost increases, the project will continue.` | Provided that makes the condition a requirement for the result. |

Русский перевод помогает понять смысл, но не управляет английской формой напрямую. Проверяй роль каждого элемента и грамматическую модель английского предложения.

### 4.8. Произношение и восприятие на слух

In connected speech, **in case**, **unless** and **as long as** may be reduced; identify the marker from the clause relation, not only its sound. Contrastive stress can highlight the condition (*ONLY if*, *EVEN if*), changing the speaker's emphasis. Phonetic transcriptions and audio examples still require dictionary-audio verification.

Для аудирования распознавай слабые формы вспомогательных глаголов, окончания и границы смысловых групп. Не ориентируйся только на чтение по буквам.

### 4.9. Академический английский и TOEFL-перенос

- **Reading:** синтаксические связи, reference, modifiers и логические отношения.

### 4.10. Примеры для управляемого разбора

- You can borrow the equipment ___ you return it by Friday. → `provided that`.
- Take a printed map ___ your phone battery dies. → `in case`.
- ___ the cost increases, the project will continue. → `Even if`.

Для каждого примера назови целевой элемент, объясни форму, укажи, почему отвлекающий вариант неверен, и придумай собственное предложение с тем же правилом.

### 4.11. Самопроверка

Перед отправкой ответа проверь:
1. Правильно ли определена функция конструкции?
2. Согласована ли форма с подлежащим и временной перспективой?
3. Не перенесён ли русский порядок слов напрямую?
4. Не смешаны ли две похожие модели?
5. Не сильнее ли утверждение, чем позволяют контекст и доказательства?

### 4.12. Краткая памятка

- In case + clause = take precaution now; if + clause = action depends on condition.
- In case of + noun = if there is... (not a finite clause).
- Unless = except if / if not.
- As long as / so long as / provided / providing = required condition.
- Even if = the result remains despite the condition.
- Use present tense for future conditions after unless/as long as/provided/providing; do not add will.
- Avoid double negatives with unless.
