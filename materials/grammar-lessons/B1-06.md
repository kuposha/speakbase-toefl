## 4. Полный конспект

### 4.1. Основная идея и функция конструкции

Third Conditional описывает воображаемое прошлое: условие, которое не произошло или было другим, и его предполагаемый прошлый результат. Обычно говорящий оценивает упущенную возможность, объясняет последствия, выражает сожаление или анализирует альтернативный ход событий.

If we had left earlier, we would have caught the train означает: мы представляем прошлое, в котором вышли раньше. В типичном контексте мы вышли поздно и не успели на поезд. Эта конструкция не меняет прошлое; она позволяет рассуждать о нём. Контекст устанавливает реальные факты, поэтому не надо превращать каждое условное предложение в доказательство конкретного события.

### 4.2. Формирование и грамматическая модель

| Часть | Модель | Пример |
|---|---|---|
| Условие | if + had + V3 | If I had studied |
| Результат | would have + V3 | I would have passed. |
| Возможность | could have + V3 | I could have passed. |
| Неуверенный результат | might have + V3 | I might have passed. |
| Отрицательное условие | if + hadn't + V3 | If I hadn't missed it |
| Отрицательный результат | wouldn't have + V3 | I wouldn't have been late. |

В had + V3 had — вспомогательный глагол Past Perfect. В результате после would/could/might используется have, а не had/has; затем V3. Сокращение I'd неоднозначно: If I'd known = if I had known; I'd have helped = I would have helped. В вопросе What would you have done if…? инверсия в главной части. Порядок частей можно менять: I would have helped if I had known. Запятая обычно отделяет начальную if-часть.

### 4.3. Как выбрать подходящую форму

Определи, что уже произошло в прошлом, и какое альтернативное условие ты представляешь. Если и условие, и результат относятся к прошлому, используй had + V3 и would/could/might have + V3. Если результат относится к настоящему, это может быть Mixed Conditional; его подробный разбор будет на B2.

Would выражает предполагаемый результат при воображаемом условии, could — возможность/способность, might — менее определённую возможность. Например, If the team had tested the device, it might have found the fault (возможно, обнаружила бы). Could have found также возможен в подходящем контексте, но меняет оттенок. Не выбирай модальный глагол механически по переводу: выясни, какую степень уверенности выражает говорящий.

### 4.4. Сравнение с близкими конструкциями

| Пример | Значение |
|---|---|
| If I have time, I'll help. | Открытое будущее условие. |
| If I had time, I'd help. | Воображаемая ситуация сейчас. |
| If I'd had time yesterday, I'd have helped. | Воображаемый прошлый исход. |
| If I'd studied harder, I would know more now. | Прошлое условие, настоящий результат (mixed). |
| I didn't study enough, so I failed. | Сообщение о реальных событиях. |

### 4.5. Примеры с переводом и объяснением

| English | Перевод | Почему это подходит |
| --- | --- | --- |
| If we had checked the address, we wouldn't have got lost. | Если бы мы проверили адрес, мы бы не заблудились. | Альтернативный прошлый исход. |
| If I had known about the deadline, I would have applied. | Если бы я знала о сроке, я бы подала заявление. | Упущенная возможность. |
| If the team had tested the device, it might have detected the fault. | Если бы команда проверила устройство, она, возможно, обнаружила бы неисправность. | Неуверенный результат. |
| What would you have done if the interview had been cancelled? | Что бы ты сделала, если бы собеседование отменили? | Вопрос о прошлой альтернативе. |
| If they hadn't arrived late, they could have joined the tour. | Если бы они не опоздали, они могли бы присоединиться к экскурсии. | Возможность при отрицательном условии. |

### 4.6. Исключения, ограничения и границы употребления

В обычной условной части Third Conditional не ставится would have. Не путай had + V3 с Past Simple и would have + V3 с would + V1. Would have может встречаться и без if, если условие понятно: I would have helped, but I was ill.

Had I known… — формальная инверсия с опущенным if, но на данном уровне основная конструкция If I had known… остаётся предпочтительной. Не соединяй if и инверсию: If had I known неверно. В конструкции wish + Past Perfect также выражается сожаление о прошлом, но wish не требует второй части с would have. Это отдельная тема. В отрицании размещай not после had или would, а не между have и V3.

### 4.7. Типичные ошибки русскоязычных студентов

| Ошибка | Исправление | Объяснение |
| --- | --- | --- |
| If I would have known, I would have called. | If I had known, I would have called. | В обычной if-части нужен Past Perfect. |
| If she had studied, she would have pass. | If she had studied, she would have passed. | После have нужна V3. |
| If we had went earlier, we would have arrived on time. | If we had gone earlier, we would have arrived on time. | Gone — V3. |
| If they had not missed the bus, they would has arrived. | If they had not missed the bus, they would have arrived. | После would нужна форма have. |

### 4.8. Произношение и восприятие на слух

Слушай сокращения: If I'd KNOWN, I'd have CALLED. Первое I'd означает had, второе — would. Would have и could have часто произносятся со слабым have; на письме нельзя заменять have на of. Пауза отделяет начальное условие от результата.

Сначала прослушай или прочитай пример, затем произнеси его целиком. Обрати внимание на смысловое ударение и форму конструкции; не ориентируйся только на буквенный перевод.

### 4.9. Академический английский и TOEFL-перенос

Third Conditional подходит для анализа прошлого опыта и причин: If the survey had included more participants, the findings might have been more reliable. В Writing не выдавай такой предполагаемый исход за результат реально проведённого исследования. В Listening распознавай сожаления и альтернативные объяснения, а в Speaking кратко объясняй, что могло бы измениться в прошлом.

Это авторская практика переноса навыка. Она не является официальным заданием TOEFL и не выдаётся за официальный результат экзамена.

### 4.10. Примеры для управляемого разбора

- If we had checked the address, we wouldn't have got lost. — Если бы мы проверили адрес, мы бы не заблудились. Альтернативный прошлый исход.
- If I had known about the deadline, I would have applied. — Если бы я знала о сроке, я бы подала заявление. Упущенная возможность.
- If the team had tested the device, it might have detected the fault. — Если бы команда проверила устройство, она, возможно, обнаружила бы неисправность. Неуверенный результат.

Для каждого примера назови целевую конструкцию, объясни выбор и составь новое предложение в другом контексте. Затем перейди к заданиям: сначала диагностика, затем управляемая и самостоятельная практика, затем новые вопросы выходной проверки.

### 4.11. Самопроверка

Перед отправкой ответа проверь:
1. Реальные события отделены от альтернативного прошлого.
2. If-часть содержит had + V3.
3. Результат содержит modal + have + V3.
4. Верно выбрана V3 неправильных глаголов.
5. Есть отрицание или вопрос.
6. Степень уверенности результата выражена осознанно.

### 4.12. Краткая памятка

If + had + V3, would/could/might have + V3. Обе части относятся к альтернативному прошлому. Вопрос — would + subject + have + V3; отрицание — hadn't/wouldn't. Различай воображаемый исход и фактически произошедшие события.

Не выбирай форму только по одному знакомому слову: проверь контекст, значение и структуру. При ошибке вернись к соответствующей части конспекта и составь собственный пример.
