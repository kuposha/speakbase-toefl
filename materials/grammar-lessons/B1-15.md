## 4. Полный конспект

### 4.1. Основная идея и функция конструкции

Used to, would, be used to и get used to похожи на письме, но передают разные значения. Used to описывает прежнюю привычку или состояние, обычно уже не актуальные. Would может описывать повторявшиеся действия в установленном прошлом контексте. Be used to — быть привыкшим, get used to — привыкать.

I used to live alone — раньше я жила одна, теперь обычно нет. I'm used to living alone — я привыкла жить одна, это не кажется непривычным. I'm getting used to living alone — постепенно привыкаю. В первой конструкции to относится к инфинитиву, в двух остальных to является предлогом, после которого нужна -ing или существительное.

### 4.2. Формирование и грамматическая модель

| Значение | Модель | Пример |
|---|---|---|
| Прежняя привычка/состояние | used to + V1 | I used to work there. |
| Повторявшееся прошлое действие | would + V1 | Every morning we would walk. |
| Уже привык | be used to + noun/V-ing | I'm used to the noise. |
| Привыкание | get used to + noun/V-ing | I'm getting used to it. |
| Вопрос о прежней привычке | Did + subject + use to + V1? | Did you use to cycle? |
| Отрицание прежней привычки | didn't use to + V1 | I didn't use to drink tea. |

Be/get меняется по времени и лицу: She is used to working; They were used to working; We will get used to working; I have got used to working (BrE). В вопросе с be нужна инверсия: Are you used to working? С get в Present/Past Simple часто используется do/did: Did you get used to it? В стандартном учебном письме после did/didn't употребляй use to, хотя в реальной письменной речи встречается used to.

### 4.3. Как выбрать подходящую форму

Определи, говоришь ли ты о прежней привычке, повторявшемся действии, знакомом состоянии или процессе адаптации. Для постоянного прошлого состояния (know, live, be) обычно выбирай used to. Для повторявшегося динамического действия с ясным прошлым контекстом возможно would. Для привычности сейчас или в другой точке — be used to; для изменения — get used to.

Would для прошлых привычек обычно требует уже установленного времени: When I was a child, every summer we would visit our grandparents. Без контекста I would visit my grandparents может звучать как гипотеза. Used to прямо указывает на прежнюю привычку/состояние и не требует такого контекста. Past Simple также может описывать прошлую привычку, но не подчёркивает изменение относительно настоящего.

### 4.4. Сравнение с близкими конструкциями

| Пример | Значение |
|---|---|
| I used to walk to college. | Раньше ходила пешком. |
| When I lived there, I would walk to college every day. | Повторявшееся действие в прошлом. |
| I'm used to walking long distances. | Я привыкла много ходить. |
| I'm getting used to walking in the rain. | Я постепенно привыкаю. |
| I walked to college yesterday. | Одно прошлое событие. |

### 4.5. Примеры с переводом и объяснением

| English | Перевод | Почему это подходит |
| --- | --- | --- |
| I used to live in a small town. | Раньше я жила в небольшом городе. | Прежнее состояние. |
| When we were children, we would play outside every evening. | В детстве мы каждый вечер играли на улице. | Повторявшееся действие. |
| I'm used to studying in the evening. | Я привыкла заниматься вечером. | Адаптация уже произошла. |
| She's getting used to her new schedule. | Она привыкает к новому расписанию. | Процесс адаптации. |
| Did you use to have a bicycle? | У тебя раньше был велосипед? | Вопрос о прежнем состоянии. |
| This device is used to measure temperature. | Этот прибор используется для измерения температуры. | Пассив и цель, не привычность. |

### 4.6. Исключения, ограничения и границы употребления

Would обычно не заменяет used to при прошлом состоянии: I used to know him, а не I would know him для непрерывного знакомства. Но динамические или повторяющиеся ситуации со stative verbs иногда допускают would при подходящем контексте. Used to не имеет обычной формы для настоящей привычки: для неё нужен Present Simple.

Не путай be used to + V-ing (привык) с пассивной конструкцией be used to + V1 (используется для цели): This tool is used to cut paper означает, что инструмент используют, чтобы резать бумагу. Здесь to cut — инфинитив цели, а не привычность. Get used to требует -ing/существительное даже в будущем: You'll get used to waking up early.

### 4.7. Типичные ошибки русскоязычных студентов

| Ошибка | Исправление | Объяснение |
| --- | --- | --- |
| I am used to work late (если привыкла). | I am used to working late. | To — предлог, нужен V-ing. |
| Did you used to play tennis? | Did you use to play tennis? | Стандартная форма после did — use to. |
| I didn't use to drinking coffee. | I didn't use to drink coffee. | После used/use to в прошлой привычке нужна V1. |
| I would know everyone in the village (постоянное состояние). | I used to know everyone in the village. | Used to подходит для состояния. |

### 4.8. Произношение и восприятие на слух

Used to в значении прошлой привычки и use to после did часто звучат слитно. Слушай наличие be/get и форму глагола после to. В I'm used to WORKing ударение помогает заметить -ing, но грамматическое различие определяется всей конструкцией.

Сначала прослушай или прочитай пример, затем произнеси его целиком. Обрати внимание на смысловое ударение и форму конструкции; не ориентируйся только на буквенный перевод.

### 4.9. Академический английский и TOEFL-перенос

В Speaking сравнивай прежние привычки с нынешними: I used to study alone, but now I'm used to working in a group. В Listening различай рассказ о прошлом и адаптацию нового студента. В Writing не смешивай обычную привычность с пассивным выражением назначения устройства.

Это авторская практика переноса навыка. Она не является официальным заданием TOEFL и не выдаётся за официальный результат экзамена.

### 4.10. Примеры для управляемого разбора

- I used to live in a small town. — Раньше я жила в небольшом городе. Прежнее состояние.
- When we were children, we would play outside every evening. — В детстве мы каждый вечер играли на улице. Повторявшееся действие.
- I'm used to studying in the evening. — Я привыкла заниматься вечером. Адаптация уже произошла.

Для каждого примера назови целевую конструкцию, объясни выбор и составь новое предложение в другом контексте. Затем перейди к заданиям: сначала диагностика, затем управляемая и самостоятельная практика, затем новые вопросы выходной проверки.

### 4.11. Самопроверка

Перед отправкой ответа проверь:
1. Used to описывает прежние привычку и состояние.
2. Would используется в контексте повторения.
3. Be used to означает привычность.
4. Get used to означает адаптацию.
5. После предлога to стоит noun/V-ing.
6. Вопрос и отрицание с did образованы корректно.

### 4.12. Краткая памятка

Used to + V1 — прежняя привычка/состояние. Would + V1 — повторявшееся действие в установленном прошлом контексте. Be used to + noun/V-ing — уже привык; get used to + noun/V-ing — привыкает. Did/didn't use to + V1.

Не выбирай форму только по одному знакомому слову: проверь контекст, значение и структуру. При ошибке вернись к соответствующей части конспекта и составь собственный пример.
